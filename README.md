# Customer-churn-Analysis
Customer Churn Analysis: A detailed exploratory data analysis (EDA) of customer churn data, uncovering key trends and insights using Python.

## Overview
This repository contains an **exploratory data analysis (EDA)** of customer churn data, aiming to uncover patterns and factors influencing customer retention. The analysis uses Python libraries such as **pandas, matplotlib, and seaborn** to visualize trends and summarize insights.

## Key Insights
- Identified missing values and handled data inconsistencies.
- Converted categorical variables into meaningful numerical representations.
- Found that **26.54% of customers have churned**.
- Observed a **higher churn rate among senior citizens** compared to younger customers.
- Customers with **long-term service usage** tend to have lower churn rates.

## Features
- Data preprocessing and cleaning
- Summary statistics and missing value handling
- Exploratory data analysis using visualizations
- Correlation analysis between customer attributes and churn

## Technologies Used
- **Python**
- **pandas, numpy**
- **matplotlib, seaborn**
- **Jupyter Notebook**
